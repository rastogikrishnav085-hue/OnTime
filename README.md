OnTime is a machine-learning-powered logistics analytics application that
helps teams identify orders at risk of missing their promised delivery dates.
It combines delivery-risk scoring, model evaluation, operational insights,
and an interactive action board in one web application.

**Built with:** Python · FastAPI · pandas · scikit-learn · XGBoost · HTML · CSS · JavaScript

---

## Key Features

- **Delivery-risk scoring:** Prioritise orders that may arrive late.
- **Risk queue and action board:** Review high-risk orders and organise follow-up.
- **Model evaluation:** Compare model performance and inspect evaluation metrics.
- **Operational insights:** Explore delay patterns and risk factors.
- **Weather context:** Access forecast information through the weather endpoint.
- **Interactive dashboard:** Explore summaries, model results, and operational patterns.
- **AI assistant:** Use the available assistant engine when its provider is configured.
